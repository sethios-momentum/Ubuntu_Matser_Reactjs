Bienvenue sur mon site d'apprentissage

Cette page constitue un exercice pratique permettant de mettre en œuvre les principales balises HTML étudiées pendant le cours.

Nous allons utiliser notamment : les liens, les ancres, les images, la vidéo, les tableaux, les listes et les formulaires.

Objectif : créer une page HTML complète sans utiliser CSS.

Partie 1 : Base de HTML

Dans cette partie, nous découvrons la structure minimale d'un document HTML. 

<!DOCTYPE html>
<html>
    <head>
        <title>Mon site</title>
    </head>

    <body>
        <h1>Bonjour</h1>
    </body>
</html>

Exemple de code : <h1>Bonjour</h1>
